# CCAT-Docs

This page contains the documentation for the CCAT. The CCAT (Consulting Contact Applicatin Tool) is the tool which is used to manage applications for consulting contact, which is orgnized by ["move - studentische Unternehmensberatung e.V."](https://move-ev.de).

You can find the project's main page [here](https://github.com/move-ev-sub/ccat). This documentation is generated using [Vitepress](https://vitepress.vuejs.org/) and Markdown.
